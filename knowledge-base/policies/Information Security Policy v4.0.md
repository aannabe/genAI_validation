# Information Security Policy

**Document ID:** POL-SEC-001
**Version:** 4.0
**Status:** Current
**Effective Date:** March 1, 2025
**Supersedes:** Version 3.1 (effective June 1, 2023)
**Policy Owner:** James Wilson, Chief Technology Officer

---

## 1. Purpose
This policy defines how Insurellm protects customer, employee, and company information.

## 2. Access Control
1. Access is granted on a least-privilege basis and reviewed quarterly.
2. Multi-factor authentication (MFA) is required for all systems holding customer or employee data, and for all remote access.
3. Shared accounts are prohibited.

## 3. Passwords
Passwords must be at least 14 characters. Passwords are rotated every 365 days or immediately upon suspected compromise.

## 4. Incident Reporting
Any suspected security incident must be reported to the Security team within 24 hours of discovery. The Security team will notify affected customers in accordance with contractual obligations.

## 5. Acceptable Use
Company systems must not be used to access, copy, or distribute information the user is not authorised to view. Attempts to circumvent access controls are a disciplinary offence.

## 6. Third-Party Vendors
Vendors that will process customer or employee data must complete the Security Review before access is provisioned. Review outcomes are recorded in the Vendor Security Review Log.
